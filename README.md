# axio-new

A cross-platform AI coding agent app — a from-scratch rewrite of
[axio](https://github.com/notzenco/axio).

The original runs its own agent loop: it talks to LLM providers directly
through a declarative provider registry, executes tool calls against your
workspace, and streams the result back. This repo restarts that from a blank
slate; the previous implementation is archived and read-only.
