# ACP round 2, Windows and real use — 2026-11-16

Owner request, after 0.2.0: run axio inside a real editor (Atrium first), fill
the ACP gaps, take Windows out of experimental, and use axio for real work.
Merged under the standing rule.

## Merged

| PR | Change |
| --- | --- |
| #100 | ACP `session/list`; with client `fs` capabilities, Read, Write and Edit go through the editor (unsaved buffers, editor applies changes, edit diffs from the buffer) via a `tools::Files` trait; replayed tool calls keep their locations. |
| #101 | `project_root` never takes the home folder's `.axio` (axio's own settings) for a project marker. Before, any non-git folder under home made home the project: a trust question on Windows, and with the sandbox module the home folder writable instead of the project (from reading `prepare()`; not reproduced live). |
| #102 | Windows documented as supported (no sandbox module; Git for Windows for Bash and hooks). The edit was made by axio itself. |
| #103 | With no one to ask, refusals suggest only what would allow the call in the current mode (and the matching allow rule); `/status` says "1 turn". |

## Evidence

- Axio Atrium's real ACP client (headless `axio-host` from axio-atrium main
  `3f432c34`, through an uncommitted ignored test in a throwaway worktree,
  stub model): a turn with Bash, Write and TodoWrite completed. Permission
  requests became Atrium approval cards. Atrium recorded the messages (with
  #96's paragraph breaks), tool calls, plan, `/compact`, four modes, and the
  model and effort options. With #100, Writes went through Atrium's own
  checked file write (a separate `acpWrite` card with a diff).
- `usage_update` was implemented and removed before merge: Atrium fails a
  turn on session update kinds it does not know ("Unsupported ACP session
  update"), and ACP has no capability to opt in.
- Schema: transcripts with `session/list`, `fs/read_text_file` and
  `fs/write_text_file` decode against ACP v1.21 (35 + 13 messages, 0 invalid).
- Windows 11 (Surface), interactive terminal over `ssh -tt` (ConPTY), with a
  stub model through a reverse tunnel: slash menu and Tab, permission picker,
  Bash (`$((6*7))` evaluated), streaming, Esc stops a turn, resize, history
  and Ctrl-D exit all passed with the #101 build. The 0.2.0 build showed the
  home-folder trust question that #101 fixes. Folder `C:\Users\kian-\axio-tui`
  removed afterwards.
- Real use (owner-approved spend): `axio -p` on Sonnet 5.5 made the #102 docs
  edit in 22 s and found the misleading refusal (#103). An interactive Sonnet
  5.5 session in plan mode answered a code question with correct file:line
  citations in 34 s (~$0.16); a mid-turn steer was taken up; `/context` and
  `/status` rendered; "1 turns" fixed in #103.
- Each PR: fmt, clippy, cargo test, `e2e/all.sh` (150 passed), CI green.
